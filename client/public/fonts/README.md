# Local fonts

Latin and Latin Extended WOFF2 subsets downloaded from the official Google Fonts CSS API on 2026-10-27. Roboto and Open Sans are variable fonts with normal and italic faces. Sawarabi Mincho provides regular (400) only; display text disables font synthesis. Extended subsets include accented characters and currency symbols. Open Sans and Sawarabi Mincho do not include ₹; product prices use the locally hosted Roboto fallback for that glyph. Other unsupported glyphs use the configured system fallbacks.

All three families use the SIL Open Font License 1.1. Their unmodified licenses are included alongside these files.
