# Local fonts

- `InterVariable.woff2`: full variable Inter 100–900 from https://rsms.me/inter/font-files/InterVariable.woff2, downloaded 2026-10-29. Official project https://rsms.me/inter/; license https://github.com/rsms/inter/blob/master/LICENSE.txt stored as `inter-OFL.txt`. Used for all storefront type; includes ₹. The entry document preloads this WOFF2.
- `Manrope-Variable.ttf`: full Manrope 200–800 from the official Google Fonts repository https://github.com/google/fonts/tree/main/ofl/manrope, downloaded 2026-10-27; `manrope-OFL.txt`. Retained for administration.
- `DMSerifDisplay-Regular.ttf`: full regular 400 from https://github.com/google/fonts/tree/main/ofl/dmserifdisplay, downloaded 2026-10-27; `dmserifdisplay-OFL.txt`. Retained for the existing Muvira brand wordmark only, without synthesis.

All fonts are unmodified, locally served under SIL Open Font License 1.1 with `font-display: swap`. Storefront headings no longer force regular serif weights.
